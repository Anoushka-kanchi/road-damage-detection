# Road Damage Detection

A road damage detection project built for DataSprint 2.0 using YOLOv8.

## Model
- YOLOv8n
- Pretrained on COCO
- Fine-tuned on the provided road damage dataset

## Classes
- Longitudinal Crack
- Transverse Crack
- Alligator Crack
- Pothole

## Tech Stack
- Python
- YOLOv8
- Ultralytics
- PyTorch
